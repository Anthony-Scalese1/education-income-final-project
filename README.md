# education-income-final-project
This is my final project for my Applied Statistics for Social Scientists course. In this project, I analyzed various data across all fifty states, relating to weather, size, demographics, education, and income. I decided to determine whether or not there is a positive correlation between bachelor's degrees and income.
# Instructions
To access and utilize the script, open the "scalesa-final_project.R" file, which contains the code for my findings. To access the dataset, open the "Table Template Final Project - Codebook.csv" file.
